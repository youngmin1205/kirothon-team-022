# 빠른 리뷰 체크리스트 (해커톤용)

주어진 변경사항(`git diff` 또는 지정 파일)을 아래 순서로 점검하고, **총 5줄 이내**로 요약한다. 장황한 설명·대규모 리팩터 제안은 하지 않는다.

1. **데모 영향**: 데모 시나리오(happy path)를 깨뜨릴 위험이 있는가?
2. **보안**: AWS 키/시크릿/토큰이 하드코딩됐는가? (`.env`+환경변수로 옮기도록 지적)
3. **실패 처리**: 외부 호출(특히 Bedrock)에 에러/폴백 처리가 있는가?
4. **steering 준수**: tech/structure/team 규칙 위반이 있는가?
5. **범위**: 요청하지 않은 변경이 섞여 있는가?

## 출력 형식
- 문제가 있으면 각 항목 1줄로 지적 (파일:라인 포함)
- 문제가 없으면 `OK` 한 줄만 출력
