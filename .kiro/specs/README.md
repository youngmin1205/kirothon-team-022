# specs — 당일 생성합니다

여기는 **지금 진행 중인 spec 이 들어오는 자리**입니다. 당일 아이디어가 정해지면
`.kiro/specs/<기능>/` 에 `requirements.md` · `design.md` · `tasks.md` 세 파일이 생깁니다.

만드는 법은 `docs/day-of-playbook.md` 1-A장 "11:25~11:40 · spec 3파일"에 있습니다.
**반드시 대화형으로** 만듭니다 (`--no-interactive` 는 리허설에서 227초를 날렸습니다).

## 예시는 여기에 없습니다

리허설에서 만든 예시 spec 은 `docs/practice/spec-example-sparring/` 로 옮겼습니다.

옮긴 이유는 이 폴더가 "진행 중인 spec" 자리라서입니다. 리허설 spec 이 여기 있으면
당일 "spec 만들어줘" 할 때 Kiro 가 그걸 참고해 **다른 주제의 맥락을 끌고 올 수**
있습니다. 참고 자료로는 계속 쓸 수 있게 지우지 않고 옮겼습니다.
