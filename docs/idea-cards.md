## 아이디어: 밥은 먹었니
- 사용자: 부모님과 떨어져 사는 자취 직장인과 그 부모님
- 문제: 부모님은 매일 "밥 먹었냐, 집에 들어갔냐"를 묻고, 자녀는 같은 답을 매일 치기 귀찮아서 늦게 답하고, 그 사이 부모님은 걱정함
- 해결: 자녀가 오늘 사진 1~3장이나 한 줄을 올리면 AI가 식사·귀가·컨디션을 판정해 부모님용 큰 글씨 안부 카드를 만들어 주고, 부모님이 ❤️로 답하면 자녀 화면에 바로 표시되는 모바일 웹앱
- 데모 장면: 점심 사진과 "오늘 좀 피곤" 한 줄을 올리면 → 부모님 휴대폰 화면에 큰 글씨 안부 카드 + 밥 ✓·귀가 ✓·컨디션 △ 칩 + ❤️ 잘 받았어 / 📞 전화 버튼이 뜸
- 필요한 것: 없음 (사진 첨부·카드·상태 칩·게이지·휴대폰 틀 모두 뼈대에 있음, 발송은 mock, 샘플 사진은 직접 준비)
- (선택) 확장: 걱정 신호 에이전트("이번 주 3일 늦은 귀가" 감지) / 부모님 답장 한 줄 → 자녀 쪽 카드
- (선택) 축소안: 사진 판정이 불안하면 한 줄 텍스트 입력만 남기고, 칩 3개와 안부 카드만 보여줌

## 아이디어: 오늘 뭐 시켜
- 사용자: 팀 커피·점심 주문을 매일 단톡에서 모으는 막내·총무 직장인과 그 팀
- 문제: 단톡에 "아아2, 라떼1, 나도, 아 난 취소"가 뒤섞여서 손으로 세다 틀리고, 1인당 금액 계산과 안 정한 사람 챙기기를 매일 반복함
- 해결: 단톡 대화를 붙여넣으면 AI가 "나도·취소·샷추가·아까 그거"를 이벤트로 풀고 코드가 최종 주문·1인당 금액을 계산해 주는 PC 웹앱
- 데모 장면: 단톡 대화를 붙여넣으면 → 메뉴·옵션별 주문표 + 원문 "나도"와 따라한 주문을 잇는 연결선 + "아직 안 정한 사람 2명" 칩 + 1인당 금액 표 + 복사할 매장 주문 문구·정산 메시지 카드가 뜸
- 필요한 것: 없음 (텍스트 입력·표·칩·카드·구조화 출력 모두 뼈대에 있음, 샘플 단톡 대화·팀원 명단·메뉴 가격표는 직접 만듦)
- (선택) 확장: 메뉴판 사진에서 가격표 추출 / 팀 화분 성장·아낀 시간 누적
- (선택) 축소안: 옵션(샷추가·사이즈) 해석과 연결선을 빼고 메뉴 개수 집계와 1인당 금액만 남김

## 아이디어: 살까 말까
- 사용자: 출퇴근길에 쇼핑앱 장바구니를 보며 매일 "살까 말까" 고민하는 직장인
- 문제: 장바구니 물건마다 필요성·예산·비슷한 걸 샀는지 따지다 매일 시간을 쓰고, 결국 친구한테 "이거 살까?" 묻거나 그냥 결제함
- 해결: 장바구니 캡처를 올리면 AI가 상품·가격을 뽑아 이번 달 예산·최근 구매와 비교해 "사/보류/빼기"를 정하고, 안 산 금액이 돈나무 열매로 열리는 모바일 웹앱
- 데모 장면: 장바구니 캡처를 올리면 → 상품별 사/보류/빼기 판정 표(이유 1줄) + 이번 달 예산 게이지 + 보류 금액만큼 열매가 달린 돈나무가 뜸
- 필요한 것: 없음 (사진 첨부·표·게이지·카드·구조화 출력 모두 뼈대에 있음, 샘플 장바구니 캡처 3장·예산·최근 구매 샘플은 직접 만듦)
- (선택) 확장: 다음 날 재확인 코치 에이전트 / 판정 카드를 친구에게 공유해 한 표 받기
- (선택) 축소안: 이미지 추출이 불안하면 상품명·가격 텍스트 붙여넣기로 바꾸고, 판정 표와 예산 게이지만 남김

## 아이디어: 손들기
- 사용자: 실습·워크숍을 진행하는 강사·조교와 그 참가자 (참가자 수십~100명)
- 문제: 실습 중 막힌 참가자는 손 들기 민망해서 혼자 붙잡다 포기하고, 진행자는 누가 몇 단계에서 왜 막혔는지 돌아다니며 물어봐야 알 수 있음
- 해결: 참가자는 휴대폰에서 "다 했어요 / 막혔어요" 버튼만 누르고(에러 메시지는 선택, 익명), 진행자 화면에 단계별 막힘 막대 + AI가 에러를 묶은 공통 원인 + 지금 말할 해결 힌트 3개가 뜨는 웹앱
- 데모 장면: 참가자 화면에서 "막혔어요"를 누르면 → 진행자 화면 3단계 막대가 빨갛게 늘고 "3단계에서 7명이 막혔어요 · 공통 원인 AccessDenied(5명)" 카드와 해결 힌트 3개가 뜨고, 힌트를 보내면 참가자 화면에 "진행자 힌트가 왔어요"가 뜸
- 필요한 것: 없음 (버튼·카드·막대·구조화 출력은 뼈대에 있음, 참가자 100명 상태와 에러 메시지는 샘플 데이터, 두 화면 동기화는 같은 백엔드 메모리를 폴링)
- (선택) 확장: CLI 에러 자동 수집 / QR로 발표장에서 바로 참여 / 실습 요약(막힘 발견 시간·포기 0명)
- (선택) 축소안: 실시간 동기화를 빼고 "참가자 행동 → 진행자 화면 갱신"을 mock 재생으로 보여주고, 에러 묶기와 힌트 3개만 남김
