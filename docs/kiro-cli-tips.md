# kiro-cli 팁 (2-8) — /rewind · 세션 재개 · 크레딧

> 당일 자주 쓸 3가지. README에서도 한 줄씩 링크한다.

---

## 1. `/rewind` — 되돌리기 / 분기
요구가 바뀌어 작업이 꼬였을 때, 처음부터 다시 하지 말고 이전 프롬프트 지점으로 되돌아간다.

```
> /rewind
```
- 돌아갈 턴을 고르면 그 지점에서 **새 세션으로 분기**해 이어간다(원래 흐름은 보존).
- 다른 접근을 실험하거나, 에이전트가 잘못 든 방향을 되돌릴 때.
- IDE에서는 Checkpoint로 특정 지점 복원 가능.

---

## 2. 세션 재개 (이어서 작업)
터미널을 껐다 켜도 하던 작업을 이어갈 수 있다.

```bash
kiro-cli                 # 대화형 시작
> /resume                # (또는 세션 목록에서 이전 세션 선택)
```
- 재부팅/터미널 종료 후에도 **직전 세션의 맥락을 복구**.
- 여러 세션을 돌린다면 어느 디렉터리의 어떤 세션인지 메모해두면 좋다.
- 멀티 세션을 많이 돌릴 계획이면 **Kiro Crew** 데스크톱 앱이 세션 관리에 유리.

---

## 3. 컨텍스트 압축 `/compact`
세션이 길어져 느려지거나 토큰이 많이 들면 대화를 요약·압축한다.

```
> /compact
```
- 긴 세션에서 **토큰 절약 + 속도 회복**.

---

## 4. 크레딧 / 사용량 확인
- 로그인한 플랜의 남은 크레딧을 확인한다 (Free = 월 50, 모델 제한·rate limit).
- 확인 경로: `/usage` 또는 `/help`에서 사용량 관련 명령 확인. IDE는 하단/설정의 사용량 표시.
- 모르면 `/help`로 현재 버전에서 쓸 수 있는 명령을 먼저 본다.

> ⚠️ 정확한 명령 이름은 kiro-cli 버전마다 다를 수 있으니, **당일 `/help`로 1회 확인**해 README에 확정해 넣자.

---

## 5. 크레딧 절약 수칙 (당일)
- 간단한 작업은 **가벼운 모델**, 어려운 작업만 상위 모델.
- 반복 agent 훅이 과하면 빈도 줄이거나 끈다.
- 탐색/실험은 `USE_MOCK=1`(백엔드)로 Bedrock 호출 없이 흐름부터 확인.
- 긴 세션은 `/compact`, 꼬이면 `/rewind` — 새 세션 남발 자제.
- 불필요한 MCP는 끄기(컨텍스트 토큰 절약).

---

## 6. 자주 쓰는 명령 요약
| 명령 | 용도 |
|---|---|
| `/help` | 사용 가능한 명령 목록 (**당일 제일 먼저**) |
| `/rewind` | 이전 지점으로 되돌려 분기 |
| `/resume` | 이전 세션 이어가기 |
| `/compact` | 대화 컨텍스트 압축 |
| `/model` | 모델 전환 |
| `/agents` | custom agent 목록/전환 |
| `/tools` | 사용 가능한 도구 확인 |
| `/usage` | 사용량/크레딧 (버전에 따라 상이) |
